# Moving and running the program

**Licence for this guide:** [Creative Commons Attribution–NonCommercial 4.0 International (CC BY-NC 4.0)](https://creativecommons.org/licenses/by-nc/4.0/).

The complete extracted folder may be copied to another Windows computer or
location. Copy the program together with the input workbook, grids, shapefiles,
optional protected areas, optional traits and logo. Do not copy `.venv` between
different computers; allow `install_and_run_windows.bat` to create a compatible
environment on the destination machine.

Moving the folder on the same computer does not require changing hard-coded
paths because input discovery is relative to the program folder. Existing
`Results` folders may be retained or archived independently.
